# Data Structures & Algorithms - Python Implementations

Collection of data structures and algorithms implemented in Python for CS 261 (Data Structures) at Oregon State University.

## Projects Overview

### Assignment 1: Python Fundamentals Review
**Topics:** Python programming fundamentals  
**Description:** Comprehensive review covering 10 programming problems including string manipulation, data processing, and algorithm implementation in Python.  
**Key Skills:** Python syntax, problem-solving, algorithm design

### Assignment 2: Dynamic Array & Bag ADT
**Topics:** Dynamic arrays, Abstract Data Types  
**Description:** Implementation of a resizable dynamic array from scratch, then built a Bag ADT using the custom dynamic array. Includes methods for adding, removing, and managing elements with automatic resizing.  
**Key Skills:** Memory management, array operations, ADT design

### Assignment 3: Linked List and ADT Implementation
**Topics:** Linked data structures, Abstract Data Types  
**Description:** Implementation of singly and/or doubly linked lists with operations for insertion, deletion, and traversal. Built additional Abstract Data Types using linked list structures with methods for efficient data manipulation.  
**Key Skills:** Pointer/reference manipulation, linked structures, memory management, ADT design

### Assignment 4: Binary Search Tree & AVL Tree
**Topics:** Binary trees, self-balancing trees  
**Description:** Implemented a Binary Search Tree (BST) with insert, delete, and search operations. Extended BST to create an AVL tree (self-balancing binary search tree) that maintains O(log n) operations through automatic rebalancing.  
**Key Skills:** Tree traversal, recursion, balancing algorithms, Big-O analysis

### Assignment 5: MinHeap Implementation  
**Topics:** Heap data structure, priority queues  
**Description:** Built a minimum heap using the dynamic array from Assignment 2. Implemented heap operations including insert, remove_min, and heapify while maintaining the heap property that parent nodes are smaller than their children.  
**Key Skills:** Heap operations, tree-based structures, priority queue algorithms

## Technologies Used
- **Language:** Python 3.13
- **Testing:** Unit tests (provided by course)


To run tests (if included):
```bash

```
